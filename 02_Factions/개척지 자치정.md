# 개척지 자치정

> 우주 개척으로 형성된 식민지들이 **지구로부터 독립해 수립한 자치정부들**의 총칭. [[D단계 시공간공학 문명|항성간 이동 기술]]의 제약으로 지구의 통제력이 약해진 결과 독립했고, **왕정·귀족정·민주정·군정 등 제각각의 정체로 난립**함. 이들의 내전이 [[통합 연방 정부]] 성립의 전사(前史). (출처: author-memo-history-2026-06)

## 성립 배경
- 우주 개척 지속 → **지구–개척지 위계 동요**.
- **항성간 이동 기술의 제약**으로 지구의 개척지 통제력 약화. → [[D단계 시공간공학 문명]]의 "관문·항로 장악=권력", "중심부–외곽 격차" 원리의 발현.
- 결과: 개척지들이 **독립**, 각자 자치정 수립.

## 정체의 난립
다양한 정부 형태가 동시다발로 출현(통일된 모델 없음):

| 정체 | 성격 |
|------|------|
| 왕정 | 단일 군주 세습 지배 |
| 귀족정 | 소수 명문가의 과두 지배 |
| 민주정 | 시민·대의 기반 통치 |
| 군정 | 군부 주도 통치 |

> 이 다양성이 곧 [[통합 연방 정부]]가 **단일 제국이 아니라 연립**이 될 수밖에 없던 이유. 서로 다른 정체를 무력으로 통일하지 못하고 정치적으로 연합함.

## 본편과의 연결
- 연방 **원로원(상원)에 대표를 보내는 연립 구성 단위**. 각 자치령이 의석을 가지며 연방의 분권적 본체를 이룸.
- 독재·공위를 거치며 **반(反)[[프르미에 크뤼]] 세력**이 옛 자치정 전통(특히 비(非)지구·외곽 세력)에서 결집할 잠재적 뿌리(미확정).

## 미확정 (작가 결정 필요)
- 구체적인 **자치정 국가들의 이름·수·위치**.
- 통합 후 **잔존 형태**(자치 유지? 해체? 연방 주(州)로 편입?).
- 본편 시점 **반발 세력과의 계보 관계**.
