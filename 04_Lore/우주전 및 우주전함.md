# 우주전 및 우주전함

> 《Interstellar War》 세계관의 **함종 체계**. [[함대 편제 (ORBAT)]] 편제 단위에 배치되는 함종 5종을 정의함. 전투 교리·교전 양상은 미확정.

## 함종 5종

| 함종 | 역할 | 규모·위치 | 비고 |
|------|------|-----------|------|
| **전함(戰艦, Battleship)** | 최대 타격력. 직접 교전 핵심. | 타격전단에 1~2척 | 가장 크고 강함 |
| **순양함(巡洋艦, Cruiser)** | 독립 작전 가능한 다목적 중형함. 전단 기함. | 타격전단에 1척(기함) / 독립 운용 가능 | 전함보다 운용 유연 |
| **구축함(驅逐艦, Destroyer)** | 전대(戰隊)의 주축. 다목적 교전(대함·방공). 전단 내 **외곽 스크린** — 전대로 편성되어 독자 교전 가능. | 전대에 6척 | 외곽·독자. 미해군 DESRON 대응 |
| **호위함(護衛艦, Frigate)** | 전함·순양함 **내곽 밀착 호위** 전담. 전함에서 이탈하지 않음. 구축함(외곽·독자 교전) ↔ 호위함(내곽·전함 전용)의 이중 스크린. | 타격전단 직속 2척 | 내곽·전담 |
| **초계함(哨戒艦, Corvette)** | 성계 순찰·관문 감시·초계. 최소형. 전대에 배속 시 전단 **전방 경계(피켓)** 역할 — 적 전대의 접근을 조기 탐지. | 전대에 3척 / 성계 방어대 | 구 '초계정' 개념 |

## 편제별 배치

| 편제 단위 | 함종 구성 |
|-----------|-----------|
| **성계 방어대** | 초계함 중심 고정 방어자산 |
| **전대(戰隊)** | 구축함 6 + 초계함 3 = **9척** |
| **타격전단(打擊戰團)** | 전함 1~2 · 순양함 1(기함) · 호위함 2 · 구축함·초계함 2전대 · 지원 ≈ **25척** |
| **함대(艦隊) 이상** | 전단 복수 집합 — 편제 상세는 [[함대 편제 (ORBAT)]] |

## 무기 체계 범주 (D단계 기반)

> [[D단계 시공간공학 문명]]에서 확정된 "반물질 병기·시공간 왜곡 무기·항성에너지 무기·관성 제어" 네 기술 축에서 파생됨. **금기 무기**(행성 파괴급·웜홀 붕괴 연쇄·항성 불안정화)는 탑재 불가 — 사용 시 문명 전체의 응징 대상.

| 무기 유형 | 기술 기반 | 특성 | 주 탑재 |
|-----------|----------|------|---------|
| **시공간 왜곡포** (용어 미확정) | 시공간 곡률 왜곡 투사 | 최강 화력. 충전 시간 필요. 관문·수비 함대 제압용. 금기 무기(웜홀 붕괴)와 출력 차원이 다름. | 전함 주포 |
| **반물질 어뢰** | 반물질 집약 탄두 + 자율 유도 | 중~장거리 타격. 관문 봉쇄·거점 공격 겸용 가능. | 전함·순양함·구축함 |
| **에너지 빔포** | 항성 에너지 기반 고밀도 빔 | 장거리 정밀 타격. 출력 조절로 대함~방공 겸용. | 순양함·구축함 이상 |
| **관성 가속 탄체** | 관성 제어 기술로 가속한 운동에너지 투사체 | 저비용·고신뢰. 방어막 소진 후 물리 장갑 타격에 효과적. 상대론적 속도 이하(금기 기준 이하). | 전 전투함 |
| **근접 방어망(PDS)** | 고속 에너지 포 + 자동 요격 제어 | 어뢰·소형함·파편 요격. 전 함종 탑재. 호위함에서 강화형. | 전 함종 |

**방어 체계:**

| 방어 체계 | 기술 기반 | 특성 |
|-----------|----------|------|
| **시공간 방어막** | 국소 시공간 곡률로 충격·빔 굴절·흡수 | D단계 핵심 방어. 집중 공격에 점진적으로 소진됨. 등급은 함종 크기에 비례. |
| **다층 물리 장갑** | 고밀도 합금 + 반응 장갑층 | 방어막 소진 후 최후 방어선. 전함이 최중, 초계함이 최경. |
| **관성 상쇄 시스템** | 관성 제어 기술 | 방어막·장갑 돌파 후 내부 피해 경감. 전 함종 탑재. |

## 함종별 무장·방어

### 전함 (Battleship)

| 항목 | 내용 |
|------|------|
| **주포** | 시공간 왜곡포 (1~2문) — 최강 화력. 충전 시간 필요. 관문 수비 함대 제압 전담. |
| **부무장** | 반물질 어뢰 발사관, 에너지 빔포(보조·연속 타격), 근접 방어망(PDS) |
| **방어막** | 시공간 방어막 **최중급** |
| **물리 장갑** | 다층 장갑 **최중** |
| **설계 논리** | 관문 쟁탈전(제3기~)의 핵심 교훈 — 관문 자체를 파괴하지 않고 **수비 함대를 제압**하는 화력. 금기 무기(웜홀 붕괴)와 달리 함대 교전 범위에 출력이 제한됨. 최중 방어는 호위함(내곽)과 중첩하여 이중 방어층을 구성함. |

---

### 순양함 (Cruiser)

| 항목 | 내용 |
|------|------|
| **주포** | 에너지 빔포 (2문) — 전함보다 출력 낮으나 연사 유리. |
| **부무장** | 반물질 어뢰 (독립 작전 시 대전함 비대칭 타격), 근접 방어망(PDS) |
| **방어막** | 시공간 방어막 **중급** |
| **물리 장갑** | 다층 장갑 **중** |
| **지휘 설비** | 기함 전용: 고출력 초광속 통신 안테나, 전술 처리 강화 — "통신 지연과 현장 판단" 원리(분산 지휘 전통) 대응. |
| **설계 논리** | 독립 작전 가능해야 하므로 전함에 준하는 자체 타격력 필요. 단 주포 화력은 전함 이하 — 함대 기함 역할과 기동 유연성이 우선. |

---

### 구축함 (Destroyer)

| 항목 | 내용 |
|------|------|
| **주포** | 속사 에너지포 (다수) — 근~중거리 연속 타격. 대함·방공 겸용. |
| **부무장** | 반물질 어뢰 (2~4문, 적 대형함 비대칭 타격), 방공 전용 PDS (전단 방공 지원 겸) |
| **방어막** | 시공간 방어막 **경중급** |
| **물리 장갑** | **경장갑** — 방어보다 기동성 우선 |
| **설계 논리** | 외곽 스크린의 핵심 요구사항 = **독자 교전 능력**. 적 구축함 전대와 맞상대할 수 있어야 하며, 어뢰로 전함급 비대칭 타격도 가능해야 함. 가벼운 장갑은 기동으로 보완 — 전대 단위 연계 전술이 전제. |

---

### 호위함 (Frigate)

| 항목 | 내용 |
|------|------|
| **주무장** | 근접 방어망(PDS) **강화형** — 전함을 향한 어뢰·소형함·파편을 전담 요격. 전체 무장의 중점. |
| **부무장** | 경에너지포 (1~2문) — 최소 반격 능력. 근거리 한정. |
| **방어막** | 시공간 방어막 **중경급** — 전함 주위에서 방어막이 중첩, 실질적 이중 방어층 구성. |
| **물리 장갑** | **중경장갑** |
| **설계 논리** | 전함에서 이탈하지 않는 내곽 호위 전담 → 자체 공격력보다 **전함 보호 전용 방어망**이 핵심. 구축함(외곽·독자 교전)과 역할이 명확히 구분됨. |

---

### 초계함 (Corvette)

| 항목 | 내용 |
|------|------|
| **무장** | 경에너지포 (2문), 기본 PDS (자기 보호용) |
| **방어막** | 시공간 방어막 **경급** |
| **물리 장갑** | **경장갑 — 최소한** |
| **핵심 장비** | **탐지·감시 센서 강화** — 광역 탐지·관문 모니터링·피아 식별. 전투력보다 **이것이 함종 정의**. |
| **기동성** | 전 함종 중 최고 — 전투 회피·정보 전달 우선. 교전 목적이 아니라 **탐지·생존·보고**. |
| **설계 논리** | 전방 경계(피켓) 역할 = 위협을 먼저 탐지하고 전단에 알리는 것. 전투 능력은 도주 + 최소 자기 방어 수준. 강한 적과 맞상대하는 설계가 아님. |

## 지원함 (별도 분류)
- **군수·지원함** — 전투함 아님. 편제 내 보조 전력.

## 전략 수준 FTL 활용 (확정 — [[성간 전쟁 변화사]] 기반)
- **워프형** — 기습·우회·특수작전. 관문에 얽매이지 않는 자유 기동.
- **웜홀 관문형** — 주력 전개·대규모 보급. 핵심 항로 봉쇄·돌파.
- **초공간 항로형** — 측면 침투·밀수·비정규 작전.

## 미확정 (작가 결정 필요)
- 순양함 독립 작전의 구체적 성격 (워프형 자유기동과 무관)
- **시공간 왜곡포의 정식 용어** — 세계관 내 명칭 (ex: "곡률포", "중력포", "메트릭 포", 고유 명칭 등)
- **무기 체계 전반의 세계관 내 명칭** — "반물질 어뢰", "에너지 빔포" 등이 작중 사용 용어인지, 다른 명칭이 있는지
- 각 함종의 포문 수·사거리·충전 시간 등 구체 수치
- 전투 교리·교전 양상 — 개별 전투에서의 전대 전술, 교전 거리·진형, 관문 돌파전 절차 등 전술 레벨 상세
- 함종별 전투 묘사 관례 (함교 묘사, 함선 이름 규칙 등)
