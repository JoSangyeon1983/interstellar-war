# 즉시 거주가능 행성 수 추정 ("에덴급" 행성)

> 보수치 **3억 개**(거주가능대 후보)에서 "맨몸으로 즉시 야외 활동 가능"한 조건을 필터링하면 **약 9만 개** (3억의 약 0.03%). 광활한 스페이스 오페라의 **희귀 노른자위 행성** 수치로 채택.

## 전제

- 톤: **광활한 스페이스 오페라**, 거주가능 후보 앵커 = **3억 개**(보수치). → [[은하 내 거주가능 행성 수 추정]]
- "즉시 거주가능(immediately habitable / 에덴급)" 정의: 우주복·돔 없이 **인간이 곧장 야외 활동 가능**.
  필요 조건 = 호흡가능 O₂ 대기 + 적정 기압·기온 + 견딜 중력 + 비독성 환경.

## 필터 캐스케이드

| # | 조건 | 통과율 | 잔존 |
|---|------|--------|------|
| 시작 | 거주가능대 후보(보수치) | — | 300,000,000 |
| A | 지구급 대기 보유 | ×0.30 | 90,000,000 |
| B | 견딜 만한 중력(≈0.4~1.6 g) | ×0.50 | 45,000,000 |
| C | 온화한 기온대 존재 | ×0.40 | 18,000,000 |
| D | 생명 발생 | ×0.10 | 1,800,000 |
| E | 산소 광합성 생물권 + 호흡가능 O₂·기압 | ×0.10 | 180,000 |
| F | 비독성·즉시 안전 | ×0.50 | **≈ 90,000** |

- **결과: 약 90,000개** (10⁴~10⁵ 자릿수), 3억의 **약 0.03%**.
- 가장 결정적 필터는 **E(호흡가능 산소 대기)** — 지구도 산소 광합성 생물이 수십억 년에 걸쳐 대기를 산소화한 결과임. 자유 산소는 성숙한 생물권 없이는 존재하기 어려움.

> 통과율은 측정값이 아니라 **작가 조절용 가정값**임.

## 조정 시나리오

| 톤 | 즉시 거주가능 수 |
|----|------------------|
| 더 빡세게(E·F 절반) | 약 1만~3만 개 |
| **권장(위 표)** | **약 9만 개** |
| 더 후하게(생명·산소 발생률↑) | 약 30만~100만 개 |

## 설정 의미

- **9만 개** = 은하 전역 수백 세력의 본거지가 될 만큼 많되, 후보 대비 0.03%라 **쟁탈 대상이 될 만큼 귀함** → 전쟁 명분 성립.
- 나머지 ≈3억 개 후보는 **테라포밍 대상**으로 잔존 → "에덴급 행성" vs "개척(테라포밍) 행성" 위계 발생. 테라포밍 기술이 세력 우위의 핵심 자원.

> ⚠️ 미확정(canon 후보): 9만은 세계관 설정용 추정이며 실제 천문 측정치가 아님. 작가 최종 확정 시 canon 페이지로 승격할 것.

## 행성 등급 연결
- **에덴급 = [[행성 분류 체계 (A~E급)|A급 (자연 거주 가능)]]** (출처: chatgpt-dstage-civ). PDF의 "희귀한 전략 자산" 서술과 9만 개(0.03%) 산출이 정확히 부합 → 상호 검증됨.
- 단 D단계 문명의 실제 대중 거주는 C~E급(특히 거대구조물 E급)에 분산됨. A급은 희소·상징·전략 가치 중심.
